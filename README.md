# Banking Website

## About
This is a small personal project I made to practice web development. It's a simple banking website where you can create an account, log in, check your balance, send money to other users, and see your transaction history.  

I built it from scratch using PHP for the backend, MySQL for the database, and HTML/CSS/JavaScript for the frontend. Everything here is for learning purposes and to see how a basic banking system could work online.

## Features
- User registration and login (authentication using PHP sessions)  
- Check account balance  
- Transfer money to other users  
- View detailed transaction history  
- Responsive layout for desktop and mobile  

## Technologies used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL (XAMPP)  
- **Authentication:** PHP sessions  

## How to run it
1. Install XAMPP and start Apache + MySQL.  
2. Put the project folder in `htdocs`.  
3. Import the SQL file into MySQL using phpMyAdmin.  
4. Open your browser and go to `http://localhost/your-project-folder/`.  

## How it works
After you register and log in, you can see your account balance and a list of your transactions. You can also transfer money to other users by typing their username and amount. Everything is saved in the database.
