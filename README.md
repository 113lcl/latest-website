# Banking Website

## Description
This is a small personal project: a simple banking website built from scratch. The goal of this project was to practice full-stack web development, including frontend, backend, and database integration.  

The website allows users to create accounts, log in, check their balance, make transfers to other users, and view a history of their transactions. All features are implemented for learning purposes and to demonstrate how a basic banking system could work in a web environment.

## Features
- User registration and login with password protection  
- Check account balance  
- Transfer money between users  
- View a detailed history of transactions  
- Responsive layout that works on desktop and mobile  

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript (or React/Vue if applicable)  
- **Backend:** Node.js and Express (or Django/Flask if using Python)  
- **Database:** PostgreSQL / MongoDB (your choice)  
- **Authentication:** JWT or session-based authentication
